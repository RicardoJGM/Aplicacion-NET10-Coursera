# Aplicación .NET 10 - Minimal API

Hola, esta es una aplicación creada con fines de aprendizaje a través de un curso en línea de Coursera.

## Descripción

La aplicación cuenta con una estructura sencilla en la que se implementan los siguientes conceptos:

- Endpoints con operaciones CRUD:
  - `GET`
  - `POST`
  - `PUT`
  - `DELETE`

- Implementación de *middlewares* para:
  - Manejo global de errores.
  - Autenticación básica mediante token.
  - Registro de eventos en consola de las solicitudes realizadas por los clientes.

- Clases de modelos utilizadas para la serialización y deserialización de datos en los diferentes endpoints.

## Objetivo

Este proyecto tiene como propósito reforzar los fundamentos de desarrollo de APIs con **.NET 10 Minimal API**, aplicando buenas prácticas en la gestión de solicitudes, manejo de errores, autenticación y modelado de datos.
